# Поиск по статьям Хабра

Поисковик по собранным статьям Хабра. Запрос можно написать своими словами — например, «как делать отчёты Word из таблиц Excel» — или ввести точное название вроде `ExecuteExcel4Macro`. В выдаче показаны заголовок, ссылка и отрывок из каждой статьи.

## Как запустить

Нужен Python 3.10 или новее. Установите зависимости из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Для гибридного поиска также нужны Docker Compose, ключ MWS и два индекса. Если вы только клонировали репозиторий, возьмите готовый корпус или [соберите статьи](docs/SCRAPING.md), затем подготовьте [коллекцию в Qdrant](docs/BGE_M3.md) и [индекс Tantivy](docs/TANTIVY.md) из одного корпуса. Корпус и индексы хранятся локально.

Когда индексы готовы, запустите:

```bash
./run.sh
```

Скрипт запустит Qdrant и веб-приложение. Ключ MWS берётся из переменной `MWS_API_KEY` или вводится в терминале. Откройте [127.0.0.1:8000](http://127.0.0.1:8000). Если порт занят, запустите `./run.sh --port 8001`. Чтобы остановить веб-приложение, нажмите Ctrl+C; Qdrant продолжит работать в фоне.

Если нужен только поиск по словам, запустите `./run.sh --engine tantivy`: он работает с готовым индексом Tantivy без Docker и ключа MWS. Для поиска только по смыслу есть `./run.sh --engine bge-m3`.

## Как устроен поиск

Скрапер сохраняет статьи в SQLite. Tantivy строит обратный индекс по заголовкам и полным текстам. Для поиска по смыслу статьи разбиваются на фрагменты: BGE-M3 преобразует их в векторы, а Qdrant хранит векторы вместе с текстом фрагментов.

По умолчанию оба поиска идут параллельно. Tantivy ищет совпадения по словам, пока MWS вычисляет вектор запроса с помощью BGE-M3, а Qdrant находит близкие фрагменты. Затем RRF объединяет два списка: чем выше место статьи, тем больше баллов она получает; если статья есть в обоих списках, баллы складываются.

Страница показывает первые пять статей. Кнопка «Показать ещё» раскрывает уже найденные результаты, до двадцати на запрос. Если опечаточник предлагает исправление, поиск по исправленной фразе начинается после нажатия на подсказку.

## Что показала проверка

На 24 контрольных запросах гибрид дал в первой пятёрке в среднем **33,3% релевантных статей**, а BGE-M3 отдельно — **28,3%**. Поэтому гибрид выбран основным режимом. Это результат на небольшой выборке с предварительной разметкой. В [таблице метрик](docs/evaluation/SEARCH_METRICS.md) есть сравнение всех трёх режимов и пояснение, как измерялось время.
