# Метрики поисковика по Хабру

Три режима проверены на одинаковых 24 запросах и корпусе из 2 665 статей. Разметка предварительная: 848 оценок пар «запрос — статья», 505 уникальных статей. Неразмеченные статьи при подсчёте считаются нерелевантными. Запросов без ответа в выборке нет. RRF объединяет по 50 кандидатов BGE-M3 и Tantivy с равными весами.

| Режим | Как устроен поиск |
| --- | --- |
| BGE-M3 | По смыслу через MWS и Qdrant |
| Tantivy | По словам через локальный обратный индекс |
| Гибрид RRF | Объединяет два списка по позициям статей |

Precision без суффикса делит число полезных статей на размер фактической выдачи (до пяти); Precision@5 всегда делит на пять. Recall считается по всем известным полезным статьям для запроса. MRR показывает, как высоко находится первый полезный ответ; nDCG также учитывает порядок остальных статей и степень их релевантности.

**На этом наборе гибрид дал больше полезных статей в первых пяти и десяти результатах, чем BGE-M3.** У обоих MRR равен 1: первый результат был полезным на каждом запросе.
